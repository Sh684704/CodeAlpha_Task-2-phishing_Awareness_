This project is a professional phishing awareness training presentation developed as part of the CodeAlpha Cyber Security Internship. It explains phishing attacks, social engineering, fake websites, phishing emails, and cybersecurity best practices.

- Identify phishing emails
- Detect fake websites
- Learn social engineering techniques
- Stay safe online

- Types of Phishing
- Social Engineering
- Phishing Emails
- Fake Websites
- Protection Tips
- Password Security
- Multi-Factor Authentication (MFA)
- Cyber Hygiene
